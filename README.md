## 产品化 5 问

1. **痛点/需求**：你解决的核心问题是什么？这个问题对目标用户有多痛？（请用一句话描述 + 举例场景）
痛点是用户需要一个简单高效的方式来管理和发布博客内容，而现有的工具往往过于复杂或功能不全。  
   场景：小张想写博客，但每次都要花很多时间在格式化和发布上，导致他经常放弃。

2. **目标用户**：谁最迫切需要这个解决方案？他们现在的替代方案是什么？（请描述 1–2 个典型用户画像）
   不懂编程的小白，或者想要拥有个人日记网站或者博客的人群。他们通过astro 来快速搭建博客。

3. **核心功能**：你的产品最必要的 1–3 个功能是什么？（请按优先级排序）
    1. 快速创建博客（使用astro 博客模版）
    2. 快速发布博客（部署到github pages或者vercel）
    3. 内容管理（支持markdown编辑器、图片上传和管理）

### 举个示范（假设想法是「AI 记账 App」）

1. **痛点**：年轻人「月光」却不清楚钱花哪儿了——每次记账坚持不过 3 天。  
   场景：小美月底发现余额不足，却想不起大额支出。

2. **目标用户**：20–30 岁一二线城市白领，现用 Excel 或支付宝自带账本，但嫌麻烦。

3. **核心功能**：  
   ① 一键导入账单（支付宝/微信）自动分类；  
   ② AI 语音记账（说一句话就记一笔）；  
   ③ 每月「败家预警」（超预算时弹窗提醒）。

4. **差异化**：比传统账本「省 80% 操作时间」，AI 分类准确率 95%+。

5. **验证方式**：用 Notion 模板 + 手动帮 10 个目标用户导入账单，观察 7 天留存率。
